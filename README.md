# CSharpPracticum

Консольный практикум по C#. Для запуска используйте `dotnet run`. Выберите уровень, затем номер задания. Для выхода введите `0` или `q`.

## Статус заданий

| Уровень | Задания | Статус |
| --- | --- | --- |
| Базовый | 1–15 | Добавлены в меню; задание 15 описывает Git-практику |
| Средний | 16–35 | Добавлены в меню; задание 35 описывает Git-практику |
| Продвинутый | 36–45 | Решения добавлены в меню; задание 45 покрыто xUnit-тестами |
| Продвинутый | 46–50 | Добавлены пункты меню с инструкциями к Git-практикам; выводы нужно сохранить в `git-notes.md` после выполнения |

## Что изучается

- Уровень 1: основы C#, циклы, массивы, строки и Git.
- Уровень 2: коллекции, ООП, LINQ, файлы и Git.
- Уровень 3: алгоритмы, асинхронность, отмена задач, JSON, тесты и Git.

Тесты библиотеки запускаются командой `dotnet test CSharpPracticum.Tests/CSharpPracticum.Tests.csproj`.
